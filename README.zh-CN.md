# TrueDraft

**你的故事，你的声音。更清晰、更透明的文书反馈。**

[免注册互动演示](https://yangsy57272.github.io/TrueDraft/) · [English](README.md) · [下载桌面版](https://github.com/yangsy57272/TrueDraft/releases) · [反馈问题](https://github.com/yangsy57272/TrueDraft/issues) · [参与贡献](CONTRIBUTING.md)

TrueDraft 是一个开源大学申请规划与文书修改工具，提供英文和简体中文界面。你可以在同一个工作空间里研究大学、整理申请、管理截止日期和预算，并按需使用 AI 反馈修改自己的文书。

## 可以做什么

- **探索专业与大学：** 整理兴趣和活动，比较学校，查看数据来源与匹配依据。不同申请体系的数据覆盖程度不同。
- **管理申请进度：** 集中查看选校清单、材料任务、截止日期、后续事项与费用估算。
- **修改自己的文书：** 阅读写作指南和补充文书题目，自动保存草稿、比较历史版本并导出。
- **按需使用 AI 辅导：** 理解题目、梳理想法、获得段落反馈和修改计划，保留自己的经历与表达。

[查看实际界面截图](README.md#screenshots) · [阅读完整草稿与详细反馈（英文）](docs/EXAMPLE_FEEDBACK.md)。示例围绕帮助同学选择英文回复的日常经历，保留犹豫与不完美，并给出具体修改问题和完成标准；不代表真实学生的投稿或实时 AI 结果。

打开[互动演示](https://yangsy57272.github.io/TrueDraft/)，跟随一个完整的虚构申请案例，体验选校、当天计划、反馈原句定位和修改对照。无需注册或 AI 密钥；刷新后重置。也可观看[简短操作录屏](https://yangsy57272.github.io/TrueDraft/demo-tour.webm)。

## 开始使用

从 [GitHub Releases](https://github.com/yangsy57272/TrueDraft/releases) 下载对应系统的软件包：Windows x64、macOS Apple Silicon / Intel，或 Linux x64 / arm64。安装与备份方法见[桌面版指南（英文）](docs/DESKTOP.md)。

桌面版在浏览器中打开，数据保存在本机。写作和规划可离线使用。AI 是可选功能，可在“设置 → AI 连接设置”中配置；云端服务可能收取费用，使用前需同意相关数据处理。

AI 可能出错，选校分组也不保证录取或经济可负担性。请以学校官网和申请系统中的最新要求为准。
